For Each

Método exclusivo para arrays. Executa uma função para cada elemento, sem precisar de índices. É mais legível e seguro que o for tradicional para iterações simples.

let nomes = ["Ana", "Pedro", "Clara"];
nomes.forEach(nome => {
console.log("Olá, " + nome + "!"); });
Clique no botão para cumprimentar cada nome.
