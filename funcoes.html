Funções em JavaScript

Funções são blocos de códigos que recebem uma tarefa específica, e são reutilizáveis ao longo do código. Recebem parâmetros e retornam um valor por meio do comando 'return'.

Sintaxe

Um exemplo da sintaxe de uma função em java script:
function calcularArea(base, altura) {
return (base * altura) / 2;
}
console.log(calcularArea(10, 5)); // O valor no console vai ser 25

Clique no botão para calcular uma área.
