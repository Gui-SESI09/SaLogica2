Estrutura de Repetição while

O comando while executa um bloco de código enquanto uma condição for verdadeira. É usado quando não sabemos exatamente quantas vezes o código precisa repetir.
Quando a condição se torna false, o laço é interrompido. 

let contador = 1;

while (contador <= 5) {
  console.log("Número: " + contador);
  contador++;
}

// Saída no console:
// Número: 1
// Número: 2
// Número: 3
// Número: 4
// Número: 5
Clique no botão para ver o laço while em ação.
