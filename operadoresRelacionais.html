Operadores Relacionais

Comparam dois valores e retornam true ou false. Exemplos: igualdade (==), igualdade estrita (===), maior que (>), menor que (<), diferente (!= ou !==). 

let x = 5;
  console.log(x > 3);     // true
  console.log(x === "5"); // false (número ≠ string)
  console.log(x != 4);    // true
Clique no botão para ver comparações.
