Arrays

Arrays em JavaScript são estruturas de dados que armazenam múltiplos valores em uma única variável, acessados por um índice numérico começando em zero. Eles são muito úteis para organizar dados, como listas de nomes ou números, e podem armazenar diferentes tipos de dados (strings, números, até mesmo outros arrays).
Você pode criar arrays com colchetes [] e usar métodos como push() para adicionar elementos e pop() para remover.
