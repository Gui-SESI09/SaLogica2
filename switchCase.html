Estrutura de Seleção Switch/Case

Útil quando você precisa comparar uma mesma variável com vários valores possíveis. Cada valor é um case, e o break evita que os casos "vazem" para o próximo. 

let mes = 2;
  switch (mes) {
    case 1: console.log("Janeiro"); break;
    case 2: console.log("Fevereiro"); break;
    case 3: console.log("Março"); break;
    default: console.log("Mês inválido");
  }
Clique no botão para ver um mês aleatório.
