Estrutura de Repetição for

O comando for é usado para repetir um bloco de código um número determinado de vezes. Ele é dividido em três partes: inicialização, condição e incremento.
Quando a condição se torna false, o laço é encerrado. 

for (let i = 1; i <= 5; i++) {
  console.log("Número: " + i);
}

// Saída no console:
// Número: 1
// Número: 2
// Número: 3
// Número: 4
// Número: 5
Clique no botão para ver o laço for em ação.
